Q1 – Building Text Under Load: String, StringBuilder or StringBuffer?6 Marks
Bloom’s Level: K4 – Analyse
Problem Context – Railway e-Ticket Generation
A railway reservation system generates an e-ticket for every booking. Each e-ticket is built by joining many fields – PNR, passenger names, coach, berth, fare and journey details – into a single printable text block. The current code builds the ticket using the + operator inside a loop.
Your Challenge
Investigate whether the choice of String, StringBuilder or StringBuffer matters for this task, or whether the difference is negligible.
Before implementation:
Predict how the three approaches will behave as the number of fields and tickets increases.
Explain the reason for your prediction using String immutability and object creation.

Design two deliberately contrasting workloads (for example: one short ticket, 10,000 tickets with 50 fields each) and one additional workload of your own.
Implement the three approaches and record appropriate measures such as:
Execution time (System.nanoTime(), averaged over repeated runs)
Number of intermediate String objects created (estimated)
Memory used before and after

Compare your prediction with the observed behaviour.
Design Decision
The ticket generator will now run inside a multithreaded booking server, and several threads may append to a shared booking log. Determine which class you would recommend for the per-ticket text and which for the shared log, and defend your decision.
Alternative Concept and Complexity Analysis
If String.join(), StringJoiner or String.format() were used instead of StringBuilder to build each ticket, what would the solution be? Derive the time complexity of building a ticket of n fields using repeated + (O(n²) characters copied) versus StringBuilder (O(n)), and analyse the extra space created by intermediate String objects in each approach.
Evidence Expected
Reasoned prediction, three deliberately designed workloads, implementation of the three approaches, measured evidence, comparison of predicted and observed behaviour, and an evidence-based recommendation.
